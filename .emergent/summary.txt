<analysis>**original_problem_statement:**
The user wants to build a Smart Google Maps Location Scraper. The application should allow searching for locations based on predefined categories (Thrill Seeking, Super Chill, Creative, Pure Entertainment, Foodie) and various location inputs (city/zip, U.S. regions, or specific place names).

**PRODUCT REQUIREMENTS:**
- **Data Scraped:** Location Name, Address, Latitude/Longitude, Website, Instagram (if available), Short Description, and up to 3 Images.
- **Search Functionality:**
    - Search by one of the 5 predefined experience categories.
    - Search by location: City/Zip code.
    - Search by one of 5 major U.S. regions (Northeast, Southeast, etc.).
    - Search by up to 10 specific location names, with an optional 2-letter state code for each to disambiguate.
- **Results Display:**
    - Display results in a paginated grid (20 per page).
    - Flag results that are new vs. seen from previous views.
    - Flag results missing a description with a yellow border.
    - Allow removing individual results from the current view.
- **Exporting:**
    - Export all results or only selected results to a CSV file.
    - The CSV must include an Experience Type column, populated based on the search category.
    - Broken image URLs should not be included in the export.
- **UI/UX:**
    - A modern, multi-step UI for searching.
    - Tooltips for experience categories explaining what they include.
    - Checkboxes on each result card for individual selection.
- **Pages:**
    - **Search Page:** The main interface for searching and viewing results.
    - **History Page:** A log of all past searches with timestamps and expandable, text-only results lists.
    - **Configuration Page:** Shows app version info and allows for managing the keywords and location types associated with each experience category.
- **Users:** Basic user registration and login functionality.

**User's preferred language**: English
